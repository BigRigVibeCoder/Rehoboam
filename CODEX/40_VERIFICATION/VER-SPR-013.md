## 6. Lessons
1. A requirement that two implementations "refuse the same lines" is untested until a differential gate runs both on the same inputs. Self-consistency fuzzing ("refused or already canonical") cannot see a disagreement with the reference. And a differential fuzz needs a per-field boundary generator (each enum domain's edges, one past them, and 255) and a file-level mode. The Tester's 600k random cases never reached `partner_kind` 6–254 or the header grammar.
2. Features that compose need a test that composes them. Resume (T-09) and replay (T-12) each passed their own tests, and a resumed directory could not be replayed.
3. A command that refuses should refuse before it touches anything. Validate the whole request first.
4. The Architect's own ruling can be wrong. `--require-parallel` on a one-system world cannot pass; the Developer's question caught it. Check a ruling against the system set it constrains.
5. A guard on a destructive operation must cover every direction. MIN-7 refused a replay into the run's own subtree, but not into a directory that contains the run, and `remove_dir_all` then emptied it (DEF-2). Before a tool deletes a path, it proves the path is its own output, for example by a marker it wrote first.
