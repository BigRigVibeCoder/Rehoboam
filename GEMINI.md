# GEMINI.md: pointer for Gemini-based agents

This repository's rules are tool-neutral, and they bind every agent whatever its vendor (GOV-011 §1). Read these files, in this order, before any work:

1. `HANDOFF.md`: while a handoff is in progress, what is in flight, who owns it and what comes next.
2. `INBOX.md` / `INBOX2.md`: the current Architect work order and task assignments.
3. `CLAUDE.md`: the project's non-negotiables and every check. The file name is historical; the file binds you.
4. `AGENTS.md`: the briefing and reading order.
5. `CODEX/10_GOVERNANCE/GOV-009` (Git and GitHub), `GOV-010` (CI), and `GOV-011` (agent sessions, handoffs, worktree concurrency).

## Cardinal Invariants (NEVER VIOLATE)
1. **DETERMINISM:** Zero floats in Plane A (all math must use fixed-point `q16`/`Fixed` or integers).
2. **SAFETY:** `#![deny(unsafe_code)]` everywhere in `crates/`.
3. **CONTRACTS:** Code follows specs (`specs/systems/*.odd.toml`). Never alter contracts to make code pass; propose an `EVO-`.
4. **SINGLE-WRITER:** Systems read via `rh-contracts` accessors; never mutate foreign columns directly.
5. **GENERATED FILES:** Goldens, locks, baselines, and skeletons are regenerated by tools, NEVER typed.
6. **GIT:** NEVER push to `main`. Never force-push or rebase. Only push to your assigned sprint branch.

## Multi-Agent Worktree Concurrency (GOV-011 §9)
- **Worktree Isolation:** When sharing this host machine with sibling agents, work strictly in your assigned worktree (e.g. `.claude/worktrees/agent-<id>-<sprint>`).
- **Never `git checkout` in root:** NEVER switch branches in the repository root while sibling worktrees are active.
- **No bare `git stash`:** Stashes are shared across all worktrees and risk being consumed by another agent. Commit WIP instead.
- **Resource arbitration:** Coordinate with other agents before running full workspace release builds or `check_all.sh` (prevent RAM OOM / disk fill).

## Terminal & Subprocess Rules (GOV-011 §10)
- **Environment:** Always start terminal sessions with `export GIT_PAGER=cat PAGER=cat` and `source $HOME/.cargo/env` (cargo is not on default PATH).
- **No pagers or interactive prompts:** Always use `git --no-pager <cmd>` for every git command (`log`, `diff`, `branch`, `show`). Pass long output through `| head -n 60` or `| tail -n 40`.
- **No interactive commands:** Pass all flags explicitly. No bare `gh pr create`, no editor launches, no `git commit` without `-m`.
- **2-minute stall rule:** If a command shows a `:` prompt or runs with no output for > 2 minutes, abort immediately; do not stall the session.
- **Do not poll CI:** After pushing and opening the draft PR, report to the Architect. Do not loop on `gh pr checks`.

## Rust Engine Code Discipline (GOV-011 §11)
- **Inspect before edit:** Read existing type definitions and all usages with `rg -n '<TypeName>' crates/`. Extend types in place; NEVER duplicate or leave `...Old` copies.
- **Trait compatibility:** Add default implementations to new methods on shared traits (e.g. `SystemModel`) so all existing systems compile.
- **Incremental checks:** Run `cargo check -p <crate>` after EVERY edit, and `cargo check --workspace` before committing.
- **Bounded scope:** Do only the assigned work order task (`INBOX.md`). Commit once per task (`type(SPR-NNN): T-NN description`).

## Git and Merge Discipline (GOV-009)
- **Never push to `main`:** It moves only by pull request.
- **Never force-push or rebase a pushed branch:** Bring `main` in with `git merge origin/main`.
- **Architect merges:** Every PR merges with a merge commit pinned to the head SHA (`gh pr merge <N> --merge --match-head-commit <sha>`).
- **Merge conflicts in `bin/check_all.sh`** are resolved by gate name. Run `python -I bin/check_all_selftest.py inventory`.
- **Keep context small and calls few** (GOV-011 §8): restart daily from `HANDOFF.md`, batch tool calls, keep command output short.
