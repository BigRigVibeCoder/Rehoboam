# specs/ — Machine-readable contracts

These artefacts are the executable side of the plan in `docs/`. AI agents implement against them. Each one is validated by running it.

| Artefact | Purpose | How to check it |
|---|---|---|
| `manifest/registry_v0.toml` | Minimal **Mechanics Registry**: the closed vocabulary of systems with bounded parameters, archetypes, governments, succession laws, institutions, technologies, act classes, roles, channels, overlays, pattern packs, style cards, templates, values, doctrine tags, heightmap templates, climate zones, goods and the welfare-ratio basket, and the sifter's typed attributes and verbs | Loaded by the two tools below |
| `manifest/manifest_v0.py` | World-manifest schema v0 (Pydantic v2): discriminated unions, no free-string semantics. Also performs Registry-aware semantic validation: bounds, vocabulary (values, doctrines, heightmaps, climate zones), required roles, scenario horizon and speculative trajectory, creature capabilities and the S4.ecology requirement, testing se/sp, population envelope, Carbone-ratio energetics | `python -I specs/manifest/manifest_v0.py validate specs/manifest/examples/val_khor.yaml` |
| `manifest/manifest_v0.schema.json` | JSON Schema generated from the Pydantic model. Constrained decoding uses it after enums are injected from the Registry | `python -I specs/manifest/manifest_v0.py schema` |
| `manifest/examples/val_khor.yaml` | Reference world `val_khor`, on the complexity ladder's Later row (the optional 100k scale-up, P3.10): feudal realm with dragons and a father–son succession catalyst | Validates with 0 errors |
| `manifest/examples/solo.yaml` | Reference world `solo`, rung 0 of the complexity ladder (D4): one person on a 64×64 valley for 80 years, a household's food, daily life at `minutes` resolution. The world every engine change runs on first | Validates with 0 errors |
| `manifest/examples/uz_job.yaml` | Reference world `uz_job` (micro, N ≈ 60), at rung 2 (`hamlet`) of the complexity ladder: the trials of Job. Explicit cast, a household with holdings, off-map raiders, and an Adversary under a staged wager catalyst (ADR-0028) | Validates with 0 errors |
| `manifest/examples/household.yaml` | Rung 1 of the complexity ladder (BCK-002 A-06; SPR-011 ruling 18): one household, a couple and three children, template `pastoral_household`, M2 defaults. In P1a five founders age and die (no births until P1.3) | Validates with 0 errors; V-WC-04 parity |
| `manifest/examples/hamlet.yaml` | Rung 2 (SPR-011 ruling 18): `uz_job`'s 60 people, cast and household without the agent, the wager, the raiders, the overlays or the holdings, none of which P1a simulates | Validates with 0 errors; V-WC-04 parity |
| `manifest/examples/aethelgard.yaml` | Reference world `aethelgard`, not on the complexity ladder: modern metropolis with a covert hive infection and a 10-year horizon | Validates with 0 errors |
| `manifest/examples/invalid_draft_style.yaml` | Negative test reproducing the draft schema's failure modes | **Must fail** with 8 errors: horizon, two bounds violations, unknown system, unimplemented fidelity, missing successor role, creatures without S4.ecology, dragon energetics |
| `demography/brass_general_standard.toml` + `demography/selftest_brass.py` | Brass (1971) General Standard life table and Table 19 golden schedules; M2 mortality golden vectors | `python -I specs/demography/selftest_brass.py` prints `BRASS GOLDEN VECTORS: PASS` |
| `demography/selftest_m2_rung0.py` | The exact `fractions` reference of M2's rung-0 mortality algorithm (`systems/M2.demography.odd.toml` [algorithm.mortality_rung0]; SPR-011 ruling 7): K from e0 by integer bisection, survivors with 32 fraction bits, monthly `Prob32` probabilities. Checks the spec's K values, the stated widths, Brass Table 19 and the exact V-SF-02 band | `python -I specs/demography/selftest_m2_rung0.py` |
| `economy/selftest_economy.py` | M4 golden vectors: the Registry consumption basket `baskets.allen2001` (Allen 2001 Table 3: 414.899 g silver, 1,941 kcal/day, 80 g protein) and its Mediterranean variant; every item maps to a Registry good; `subsistence_kg_grain` brackets the floors Allen implies; the constant-elasticity price rule reproduces Davenant's schedule at ε ≈ 0.40 and the elasticity range contains the observed 0.18–0.87 (R12 §17–18) | `python -I specs/economy/selftest_economy.py` prints `M4 GOLDEN VECTORS: PASS` |
| `stream/selftest_virtual_telemetry.py` | Prototype of ADR-0031's virtual telemetry: a stateful engine loop and on-demand queries into a life-course log agree exactly on every sampled person-day and on who was where; random access costs about 35 µs per person-day in pure Python, and stored data is only the life-course intervals | `python -I specs/stream/selftest_virtual_telemetry.py` prints `VIRTUAL TELEMETRY: PASS` |
| `stream/compress_probe.py` | Measurement, not a contract: bytes per core event record for 1M synthetic World Stream events in Parquet (zstd 10.5, snappy 19.2, raw 37) | `python -I specs/stream/compress_probe.py <out_dir>` (needs duckdb) |
| `stream/channel_a_v0.sql` + `stream/selftest_channel_a.py` | World Stream v0 channel-A sealed-segment schema (SPR-011 ruling 13): the record header, the P1.0 kinds (`INPUT`, `EVENT`, `LIFE_ENTRY`, `LIFE_EXIT`, `STEP_DIGEST`, `KEYFRAME`), the order within an instant, one Parquet file per table per (timeline, channel, sim-year), the `verb` dictionary, no float columns. The self-test seals a synthetic run and reads it back | `python -I specs/stream/selftest_channel_a.py` |
| `systems/*.odd.toml` + `systems/lint_odd.py` | **System specs as data** (ODD-R v2, ADR-0033): one exhaustive TOML spec per simulation system, cross-checked against the Registry (parameters equal both ways), the other specs (single writer, read sets, plane rules), `03`/`09` IDs, `05.1` phases and ADRs. `--brief <id>` prints the one-page summary for the director; `--rust <id>` prints the generated code skeleton. `_template.odd.toml` is the blank form | `python -I specs/systems/lint_odd.py` prints `PASS` (warnings list owners with no spec yet) |
| `chronicle/schema.sql` | Chronicle DDL (DuckDB dialect; Parquet is the system of record), tagged by plane (A/B/C): anchored snapshots, typed causal edges, knowledge and diffusion fronts, aggregate events, SCD2 intervals, the life-course log, the facts ledger, sift matches, the visibility sidecar, base rates, the input journal (push inputs, scope, epoch, model hashes), plane hashes and the keyframe index. Includes **SQL twins** for one pattern under three declared semantics, and macros | `python -I specs/chronicle/selftest.py` |
| `chronicle/selftest.py` | Generates a uniform and a **clustered** 200k-event synthetic chronicle and asserts that the SQL twins and a reference **incremental matcher** produce **identical match sets** under `all`, `latest` + `clear_binding`, and `dedupe` semantics. Reports firing rates (on the clustered fixture, `all` fires 4.5× more than the default). Also exercises the causal-ancestor walk and as-of title queries | Exits with code 0 and prints `TWIN EQUIVALENCE: PASS` |
| `sifting/patterns.example.toml` | Pattern DSL v0 examples: setting-agnostic roles, anchored state reads, `unless` (with `bind` and anchored `where`), composable match events, declared match semantics (`selection`, `on_complete`, `dedupe`), firing budgets, completion hazards with a `threatened_role`, `death_tolerant` and `surface_from`; one three-stage pattern after Winnow (R12 §19) | `python -I specs/sifting/lint_patterns.py specs/sifting/patterns.example.toml specs/manifest/registry_v0.toml` |
| `sifting/patterns.solitary_life.toml` | Pack `solitary_life`: `life_ends`, the walking skeleton's one-clause pattern on `DEATH` (SPR-011 ruling 14) | `python -I specs/sifting/lint_patterns.py specs/sifting/patterns.solitary_life.toml specs/manifest/registry_v0.toml` |
| `sifting/lint_patterns.py` | Linter. Rejects unanchored state reads (the draft's temporal bug), unknown keys and vocabulary, omitted or invalid match semantics, missing firing budgets, multi-stage patterns without `all` + `keep`, `unless` reads of anchors not yet bound, and a `completion_hazard` without a `threatened_role` | Prints `PASS` and shows the draft rule being rejected |

Dependencies for running the checks: Python ≥ 3.11, `pydantic>=2`, `pyyaml`, `duckdb>=1.5`.

These are **v0 contracts**. They are frozen and extended in P0/P1 (`docs/11_roadmap.md`, WP P0.8), and the Rust `rh-registry` crate becomes their authoritative implementation.
