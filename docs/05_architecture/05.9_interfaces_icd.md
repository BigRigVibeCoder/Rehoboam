# 05.9 — Interface Control Document (ICD)

*Status: Draft v1.0 (2026-10-15). Interfaces are versioned contracts. AI agents implement against them, and contract tests enforce them. Signatures below are illustrative. The real ones are frozen in P0/P1 and published under `specs/`.*

---

## IF-1 Core library API (`rh-core`, Rust)

```rust
pub struct WorldConfig { pub manifest: Manifest, pub registry: RegistryVersion, pub seed: u64 }

pub trait WorldHost {
    fn create(cfg: WorldConfig) -> Result<Self, SimError> where Self: Sized;        // genesis (no burn-in)
    fn load(keyframe: &KeyframeRef, journal: &dyn JournalReader) -> Result<Self, SimError> where Self: Sized;
    fn now(&self) -> SimTime;
    fn advance_until(&mut self, stop: StopCondition, budget: WallBudget) -> AdvanceReport; // pauses on stop / auto-pause / budget
    fn apply_input(&mut self, input: JournaledInput) -> Result<InputReceipt, InputError>;  // validated; appended to journal
    fn frame(&self) -> Arc<SnapshotFrame>;                                                // immutable, read-only
    fn state_hash(&self) -> u64;
    fn fork(&self, at: SimTime, salt: BranchSalt) -> Result<ForkSpec, SimError>;         // used by Timeline Manager
    fn keyframe(&self) -> KeyframeBlob;                                                   // Arrow IPC tables
    fn drain_events(&mut self) -> EventBatch;                                             // Arrow record batches
}

pub enum StopCondition { At(SimTime), Predicate(PredicateId), NextMatch { min_salience: f32 }, Never }
```

**Invariant.** Every method except `advance_until` and `apply_input` is read-only. Calling them must not change `state_hash()`; this is enforced by the unsynced guard.

## IF-2 Input journal record

```text
JournaledInput {
  timeline_id: u32, tick: SimTime, seq: u32,
  kind: enum {
    ManifestSet, SettingChange,
    OracleMove, OracleWhisper{frame: ArgumentFrame}, OraclePierce{target}, OracleOmen{spec}, OracleWard{spec},
    PlayerAction{verb_id, args}, SpeechAct{act: SpeechAct},
    PivotalChoice{actor, decision_type, action_id, menu_hash},
    ForkOverride{spec},           // what-if inputs ("king dies of fever")
  },
  producer: enum { Player, LlmJob{job_id, model_id, weights_hash?, prompt_hash}, System },
  payload_hash: [u8; 16]
}
```

**Rules**
- Inputs are validated by the simulation before they are appended.
- A rejected input is never journaled. It returns `InputError` with a machine-readable reason.
- LLM-produced inputs carry the job ID, so audits can trace them back to gateway logs.

## IF-3 Control plane: JSON-RPC 2.0 over WebSocket (text frames)

| Namespace | Methods (requests) | Notes |
|---|---|---|
| `world.*` | `create(manifest, seed)`, `open(world_id)`, `list()`, `burnin_report(world_id)` | Genesis |
| `timeline.*` | `run(band)`, `pause()`, `run_until(cond)`, `seek(tick)`, `fork(tick, overrides?)`, `list()`, `diff(a, b, metrics)` | `seek` = keyframe + replay |
| `chronicle.*` | `query(sql_template_id, params)`, `annals(range)`, `event(id)`, `causes(id, depth, kinds)`, `effects(id, depth, kinds)` | Read-only DuckDB views. **No arbitrary SQL from clients** |
| `entity.*` | `person(id)`, `genealogy(id, depth)`, `place(id)`, `polity(id)`, `beliefs(id)` (named actors only) | Writes to the facts ledger when facts are displayed |
| `sift.*` | `patterns()`, `matches(range, filters)`, `set_autopause(thresholds)`, `rate(match_id, score, note)` | Ratings feed MOE-1 |
| `oracle.*` | `move(to)`, `whisper(target, text)` → parse preview → `confirm`, `pierce(target)`, `omen(spec)`, `ward(spec)`, `status()` | Two-step whisper: preview the parse, then confirm |
| `foresight.*` | `prophesy(predicate, horizon, n)`, `compare(predicate, intervention, n)`, `status(job)`, `cancel(job)` | Runs on rollout workers |
| `bubble.*` | `subscribe(center, radius, lod_profile)`, `move(center)`, `unsubscribe()` | Opens the binary state channel |
| `dialogue.*` | `start(person_id)`, `say(text \| audio_ref)`, `end()` | Streams `dialogue.line` notifications |
| `compile.*` | `from_prompt(text)`, `status(job)`, `gaps()` | World compiler |
| `narrative.*` | `request(form, range, style_card, options)`, `status(job)`, `export(job, format)` | Narrative compiler |

**Notifications** (server → client): `timeline.tick` (rate-limited), `timeline.paused{reason, match_id?}`, `sift.match`, `sift.partial`, `foresight.progress`, `job.progress`, `dialogue.line`, `invariant.violation` (debug builds).

**Error model.** JSON-RPC `error.code` uses ranges: −32000 to −32099 for simulation errors, −32100 to −32199 for validation errors, −32200 to −32299 for job errors. Every error carries a `data.reason` enum plus human-readable text.

## IF-4 State plane: binary columnar frames (WebSocket binary frames)

```text
FrameHeader (32 B, little-endian):
  magic u32 = 'RHFR' | schema_ver u16 | flags u16 (FULL=1, DELTA=2, ZSTD=4)
  timeline_id u32 | seq u32 | tick u64 | baseline_seq u32 | n_entities u32

Columns (each: col_id u16 | dtype u8 | len u32 | bytes), present per flags/changed mask:
  ids            u32[n]           person/creature id (low 32 bits + table tag in high bits)
  pos            u16[3n]          quantised within bubble AABB (~2 mm at 100 m half-extent)
  yaw            u16[n]
  verb           u8[n]            WALK, TILL_SOIL, PATROL, FLEE, ...
  waypoint       u16[3n]          next waypoint (client interpolates)
  lod_tier       u8[n]            T3/T2c/impostor
  appearance     u32[n]           rendezvous-hash outputs (packed slots) — sent on enter only
  status_mask    u16[n]           infected-mask, injured, carrying, ...
  changed_mask   bitset[n]        (DELTA only)
Tail: optional zstd over columns.
```

- **Rates.**
  - Full frame every 1 s; deltas against the previous frame otherwise. TCP's ordering makes this safe.
  - Transforms at 20 Hz.
  - Hydrated detail (name, mood, action text) goes over the control plane, budgeted with a priority accumulator.
- **Sizes.** R10 measured about 2.6 KB per full frame and about 1.4 KB per delta for 200 entities.

## IF-5 Python bindings (`rh-py`, PyO3/maturin)

```python
import rehoboam as rh
w = rh.World.create(manifest_path="worlds/val_khor.yaml", seed=1207)
w.advance_until(rh.Stop.at(year=200), release_gil=True)
tbl = w.frame().ledger()           # pyarrow.Table (zero-copy where possible)
events = w.drain_events()          # pyarrow.RecordBatch
h = w.state_hash()
```

The bindings are used by the world compiler (burn-in), calibration notebooks, the narrative compiler (read-only) and tests.

## IF-6 LLM Gateway job API (local HTTP+JSON, or in-process Python)

```text
POST /jobs {kind, input, schema_ref, budget{tokens,usd}, route_hint?, journal: bool}
 → {job_id}
GET  /jobs/{id} → {status, output?, cost, model_id, provider, latency_ms, refusal?, repair_rounds}
WS   /jobs/{id}/stream → token deltas (dialogue.realise)
```

**Contract**
- Outputs are validated against `schema_ref` before the job reports success.
- With `journal=true`, the gateway returns a `JournaledInput` envelope. The server then validates it and applies it through IF-1 `apply_input`.

## IF-7 Event bus (internal)

```rust
pub struct EventDraft {
  verb: VerbId, act_classes: ActClassSet, place: PlaceRef, magnitude: i32,
  roles: SmallVec<[(EntityRef, ConcreteRole, AbstractRole); 4]>,
  snapshot: SmallVec<[(EntityRef, AttrId, i32); 8]>,   // anchored predicate values
  causes: SmallVec<[(EventId, CauseKind, i16); 4]>,
  secrecy: Secrecy, tellability: u8, origin: Origin,
}
ctx.emit(draft) -> EventId   // deterministic id = (day_index << 24) | seq
```

**Ordering.** Events are totally ordered by `EventId` within a timeline. The sifter, chronicle writer and knowledge propagation all consume them in that order.

## IF-9 Versioning rules

| Item | Policy |
|---|---|
| `schema_ver` of frames, keyframe Arrow schemas, manifest versions, registry semver | Additive changes are minor; breaking changes are major and require a migration |
| JSON-RPC methods | Never change semantics in place. Add `method_v2` |
| Contract tests | Each interface has a conformance suite in `specs/`, run against every implementation (server, wheel, gdext) in CI |
