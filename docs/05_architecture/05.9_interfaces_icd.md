# 05.9 — Interface Control Document (ICD)

*Status: Draft v1.1 (2026-10-15). Decisions: ADR-0023 (wire protocol), ADR-0024 (three planes), ADR-0025 (scheduled outcomes, material inputs), ADR-0026 (identity), ADR-0034 (push inputs only). Interfaces are versioned contracts. AI agents implement against them, and contract tests enforce them. Signatures below are illustrative. The real ones are frozen in P0/P1 and published under `specs/`.*
*v1.2 (2026-10-16): push inputs only; `AwaitPull`, `AdvanceReport::Stalled`, the `Pull` class, `DeliberationAnswer` and `timeline.stalled` are removed (ADR-0034, D27).*
*v1.3 (2026-10-16): IF-7: `ctx.emit` returns a `DraftRef`; `EventId` is one counter per timeline, assigned at the level merge (`05.1` v1.6 §2, SPR-006).*
*v1.4 (2026-10-17): IF-0: the live edge's wire is `specs/stream/wire_v1.md` (SPR-026): frames of canonical lines (D43 approved 2026-10-17; ADR-0031 §1 item 4 amended) over one Unix socket per channel and timeline, `stream/t<id>/A.sock` and `C.sock`; `stream.subscribe`, `stream.unsubscribe`, `stream.status` and three notifications; the stream sockets are read-only in every version; the control endpoint (pace, tip inputs) is `control.sock` (SPR-027, P2). IF-0 is these three sockets.*

## IF-0 World Stream (ADR-0030; spec `05.10`)

The engine's primary output: one ordered, append-only, sequenced stream per timeline. Viewers tap it with their own cursors; actions land at the tip.

```text
StreamRecord header:
  timeline_id u32 | channel u8 (A=world, C=narrative) | seq u64 (contiguous per channel) | tick i64 | kind u16
Channel A kinds: EVENT (actors, act class, target, place, causal edges, anchored values) | INPUT (applied tick)
                 | DECISION_TRACE (named-mind decision: top options and utility terms) | ENCOUNTER (focus regions; ADR-0031)
                 | STEP_DIGEST (per macro step: population, prices, era state, Ψ per region; plane hashes)
                 | KEYFRAME (pointer to a full snapshot)
Channel C kinds: MATCH (partial | complete | expired | killed) | SIGNIFICANCE | SUSPENSE | VISIBILITY
Encoding: sealed per-sim-year segments as Parquet (the chronicle); the live edge as frames of canonical lines (specs/stream/canonical_v0.md;
           D43) over a Unix domain socket per channel and timeline, <run-dir>/stream/t<id>/A.sock and C.sock (specs/stream/wire_v1.md; SPR-026)
Cursor: (timeline_id, channel, seq), held by the viewer. `stream.subscribe(from: {seq} | "live")`, `stream.unsubscribe()`; `stream.status()` → tip, pace,
        sealed range, live window, run_nonce; notifications `stream.sealed`, `stream.behind`, `stream.end{reason}`. Read-only in every version: no input
        and no pace command on a stream socket; those are control.sock's (wire_v1.md §8). IF-0 = {A.sock, C.sock, control.sock}
```

- Channel A is byte-identical for the same build, Registry, manifest, seed and journal, at any pace (V-STR-01).
- Exact state at any tick comes from the materializer (keyframe + deterministic replay; V-STR-02).
- Anyone's activity on any day comes from virtual telemetry: `telemetry.where(person, day)` and `telemetry.who(place, day, block)`, computed from the life-course log and seed without replay (ADR-0031; V-STR-07).

## IF-1 Core library API (`rh-core`, Rust)

```rust
pub struct WorldConfig { pub manifest: Manifest, pub registry: RegistryVersion, pub seed: u64 }

pub trait WorldHost {
    fn create(cfg: WorldConfig) -> Result<Self, SimError> where Self: Sized;        // genesis (no burn-in)
    fn load(keyframe: &KeyframeRef, journal: &dyn JournalReader) -> Result<Self, SimError> where Self: Sized;
    fn now(&self) -> SimTime;
    fn advance_until(&mut self, stop: StopCondition, budget: WallBudget) -> AdvanceReport; // pauses on stop / auto-pause / budget
    fn apply_input(&mut self, input: JournaledInput) -> Result<InputReceipt, InputError>;  // validated; appended to journal
    fn frame(&self) -> Arc<SnapshotFrame>;                                                // immutable, read-only
    fn plane_hashes(&self) -> PlaneHashes;          // { state (A), observation (B), narrative (C) }
    fn fork(&self, at: SimTime, lineage: SaltLineage, policy: ForkPolicy) -> Result<ForkSpec, SimError>;
        // lineage = parent path + this fork's unique step; policy = { resample_on_fork: bool (rollouts),
        // keep_parent_salt: bool (what-if A/B with common random numbers) }
    fn keyframe(&self) -> KeyframeBlob;                                                   // Arrow IPC tables
    fn drain_events(&mut self) -> EventBatch;                                             // Arrow record batches
}

pub enum StopCondition { At(SimTime), Predicate(PredicateId), NextMatch { min_salience: f32 }, Never }
pub struct SaltLineage(SmallVec<[u64; 4]>);      // empty = canonical; branch_salt(t) = H(path covering t)
```

**Invariants.**
- Every method except `advance_until` and `apply_input` is read-only **with respect to plane A**. Calling them must not change `plane_hashes().state`; this is enforced by the unsynced guard. Observation APIs (pins, facts displayed) may change plane B only.
- `advance_until` never waits on a model or any other external service (ADR-0034).
- `apply_input` with `tick < now()` is refused with `InputError::PastInput`. The Timeline Manager handles it by forking at that tick first (ADR-0025).

## IF-2 Input journal record

```text
JournaledInput {
  timeline_id: u32, tick: SimTime /* i64 minutes */, seq: u32,
  class: enum {
    Push,                         // initiated outside the sim: player, Oracle, settings; the only class (ADR-0034)
  },
  kind: enum {
    ManifestSet, SettingChange, ConsoleMode{cultivator | oracle},
    OracleMove, OracleWhisper{frame: ArgumentFrame}, OraclePierce{target}, OracleOmen{spec}, OracleWard{spec},
    PlayerAction{verb_id, args}, SpeechAct{act: SpeechAct},
    ForkOverride{spec},           // what-if inputs ("king dies of fever"); only at a fork's first tick
  },
  scope: enum { None, Person(id), Household(id), Settlement(id), Region(id) },  // dependency scope (05.2 §3.2)
  producer: enum { Player, LlmJob{job_id, model_id, weights_hash?, provider_version?, prompt_hash}, System },
  payload_hash: [u8; 16]
}
```

**Rules**
- Inputs are validated by the simulation before they are appended.
- A rejected input is never journaled. It returns `InputError` with a machine-readable reason.
- **Material inputs** (anything with `scope ≠ None`) cancel and re-sample the pending timers in their scope in the `Inputs` phase. The re-sample key includes each entity's **epoch**, a plane-A counter of the material inputs that have touched that entity (ADR-0025). It is derived state, so it is not journaled. At equal ticks, inputs apply before timers.
- `seq` is assigned by the journal: the append order within the timeline, from 0 and contiguous. Inputs apply in `(tick, seq)` order, so an input scheduled for a future tick is journaled when it is issued (`05.10` §2) (SPR-007, Architect ruling 2026-10-16).
- On replay, a missing, extra or mismatched input is a **hard failure**, never a silent re-decision.
- LLM-produced inputs carry the job ID, model ID, weights hash or provider version and prompt hash, so audits can trace them back to gateway logs. Their outputs are replayed from the journal, never regenerated.

## IF-3 Control plane: JSON-RPC 2.0 over WebSocket (text frames)

| Namespace | Methods (requests) | Notes |
|---|---|---|
| `world.*` | `create(manifest, seed)`, `open(world_id)`, `list()`, `liveness_report(world_id)`, `certification_report(world_id)` | Genesis. Certification runs in the background (`05.5` §4.2) |
| `timeline.*` | `run(band)`, `pause()`, `run_until(cond)`, `seek(tick)`, `fork(tick, overrides?)`, `list()`, `diff(a, b, metrics)` | `seek` = keyframe + replay, **read-only**. Any material input sent while seeked into the past forks first and returns the new `timeline_id` |
| `chronicle.*` | `query(sql_template_id, params)`, `annals(range)`, `event(id)`, `causes(id, depth, kinds)`, `effects(id, depth, kinds)` | Read-only DuckDB views. **No arbitrary SQL from clients** |
| `entity.*` | `person(id)`, `genealogy(id, depth)`, `life_course(id)`, `place(id)`, `polity(id)`, `beliefs(id)` (named actors only) | Displayed facts are written to the plane-B facts ledger, never plane A. In Oracle mode, results are filtered by the Oracle's knowledge |
| `sift.*` | `patterns()`, `matches(range, filters)`, `set_autopause(thresholds)`, `rate(match_id, score, note)` | Ratings feed MOE-1 |
| `console.*` | `set_mode(cultivator \| oracle)`, `mode()` | Journaled (`ConsoleMode`) |
| `oracle.*` | `move(to)`, `whisper(target, text)` → parse preview → `confirm`, `pierce(target)`, `omen(spec)`, `ward(spec)`, `status()` | Two-step whisper: preview the parse, then confirm |
| `foresight.*` | `prophesy(predicate, horizon, n)`, `compare(predicate, intervention, n)`, `status(job)`, `cancel(job)` | Runs on rollout workers |
| `bubble.*` | `subscribe(center, radius, lod_profile)` (`lod_profile` ∈ `{"glyph", "3d"}`; ADR-0029), `move(center)`, `unsubscribe()` | Opens the binary state channel |
| `map.*` | `glyph_tiles(z, x, y, tick)` | Lo-fi Z0 world and travel map tiles from regional aggregates and the chronicle; settlement glyph chunks (Z1). Read-only; respects Oracle-mode filtering (ADR-0029) |
| `player.*` | `act(action)` | Street-level avatar actions (`MOVE`, `TAKE`, `GIVE`, `ATTACK`, `ENTER`, …) as journaled `PlayerAction` material inputs with a dependency scope. The new state arrives in the next frame; clients never predict it |
| `dialogue.*` | `start(person_id)`, `say(text \| audio_ref)`, `end()` | Streams `dialogue.line` notifications |
| `compile.*` | `from_prompt(text)`, `status(job)`, `mapping(job)`, `calibration_log(job)`, `gaps()` | World compiler |

**Notifications** (server → client): `timeline.tick` (rate-limited), `timeline.paused{reason, match_id?}`, `timeline.forked{from, at, timeline_id}`, `sift.match`, `sift.partial`, `foresight.progress`, `job.progress`, `dialogue.line`, `invariant.violation` (debug builds).

**Error model.** JSON-RPC `error.code` uses ranges: −32000 to −32099 for simulation errors, −32100 to −32199 for validation errors, −32200 to −32299 for job errors. Every error carries a `data.reason` enum plus human-readable text.

## IF-4 State plane: binary columnar frames (WebSocket binary frames)

```text
FrameHeader (32 B, little-endian):
  magic u32 = 'RHFR' | schema_ver u16 | flags u16 (FULL=1, DELTA=2, ZSTD=4)
  timeline_id u32 | seq u32 | tick i64 | baseline_seq u32 | n_entities u32

Columns (each: col_id u16 | dtype u8 | len u32 | bytes), present per flags/changed mask:
  ids            u32[n]           person/creature id (low 32 bits + table tag in high bits)
  pos            u16[3n]          quantised within bubble AABB (~3 mm at 100 m half-extent; ~4 mm at 130 m)
  yaw            u16[n]
  verb           u8[n]            WALK, TILL_SOIL, PATROL, FLEE, ...
  waypoint       u16[3n]          next waypoint (client interpolates)
  lod_tier       u8[n]            T3/T2c/impostor
  appearance     u32[n]           rendezvous-hash outputs (packed slots) — sent on enter only
  status_mask    u16[n]           infected-mask, injured, carrying, ...
  changed_mask   bitset[n]        (DELTA only)
Tail: optional zstd over columns.
```

- **Rates.**
  - Full frame every 1 s; deltas against the previous frame otherwise. TCP's ordering makes this safe.
  - Transforms at 20 Hz.
  - Hydrated detail (name, mood, action text) goes over the control plane, budgeted with a priority accumulator.
- **Sizes.** R10 measured about 2.6 KB per full frame and about 1.4 KB per delta for 200 entities.

### Harness rules (ADR-0030)

Every consumer of IF-0, IF-3, IF-4 and IF-5 is a **harness**: a separate process or thread pool. The engine runs headless and is complete without one.
- **The engine never waits for a harness.** Viewers read the World Stream (IF-0) with their own cursors. A viewer that falls behind the in-memory live edge reads sealed segments from disk. Nothing is dropped, and nothing back-pressures the engine. IF-4 frames are a live-edge convenience for the street bubble, not the record of the world.
- **Reads never lock the tick.** "Now" queries read the latest published `Arc<SnapshotFrame>`. History queries read the stream at rest (the Parquet chronicle through DuckDB), or the materializer for exact state at a past tick.
- **Hydration is off the tick path.** Bubble hydration (plane B) runs on the viewer side or in a materializer process. When it shares the host, it runs on its own pool capped by `observer_cpu_share` (default 25% of cores interactively, 0 in batch mode), never on simulation threads. The bubble follows the viewer's playback rate, not the engine's.
- **The only write path is the input journal, at the tip.** Material inputs (`player.act`, Oracle verbs, director edits) land at the next tick boundary after the tip, or at a scheduled future tick. An input aimed at a past tick is refused unless issued as `timeline.fork`. Non-material calls touch plane B only.
- **Verified by** V-STR-01–05, V-PERF-09 (throughput ≥ 95% of headless with harnesses attached, a stalled one included) and V-DET-06–08 (`state_hash` unchanged).

## IF-6 LLM Gateway job API (local HTTP+JSON, or in-process Python)

```text
POST /jobs {kind, input, schema_ref, budget{tokens,usd}, route_hint?, journal: bool}
 → {job_id}
GET  /jobs/{id} → {status, output?, cost, model_id, provider, latency_ms, refusal?, repair_rounds}
```

**Contract**

## IF-7 Event bus (internal)

```rust
pub struct EventDraft {
  verb: VerbId, act_classes: ActClassSet, place: PlaceRef, magnitude: i32,
  roles: SmallVec<[(EntityRef, ConcreteRole, AbstractRole); 4]>,
  snapshot: SmallVec<[(EntityRef, AttrId, Option<EntityRef>, i32); 8]>,   // anchored values: subject, attribute, optional object, value
  causes: SmallVec<[(EventId, CauseKind, i16); 4]>,
  secrecy: Secrecy, tellability: u8, origin: Origin,
}
ctx.emit(draft) -> DraftRef  // the draft's index within this step; no EventId yet
// EventId(u64): one counter per timeline, from 0. The merge at the end of each scheduler level assigns ids
// in the canonical order (05.1 §2 rule 4) and resolves DraftRef causes to them. The id carries no date.
```

**Ordering.** Events are totally ordered by `EventId` within a timeline, and `EventId` order **is** emission order `(tick, phase, seq)`. There is no back-dating: an event is always stamped with the tick at which it is emitted, and an outcome sampled for a later instant is a timer that emits when it fires (ADR-0025). The sifter, chronicle writer and knowledge propagation all consume events in that order.

**Match events.** The sifter's `match` events live in a separate ID space (`MatchId`) and are not simulation events. Editing a pattern therefore never renumbers simulation events (05.4 §2.3 item 10).

## IF-9 Versioning rules

| Item | Policy |
|---|---|
| `schema_ver` of frames, keyframe Arrow schemas, manifest versions, registry semver | Additive changes are minor; breaking changes are major and require a migration |
