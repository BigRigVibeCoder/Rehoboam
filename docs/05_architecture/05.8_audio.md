# 05.8 — Audio: Systemic Ambience, NPC Speech, Audio Drama

*Status: Draft v1.1 (2026-10-15). Source: R07. Decision: ADR-0019. v1.1: latency target tied to AUD-4. Licence verdicts depend on the audio.cpp licence table (re-checked Sep–Oct 2026) and on model cards. Spot-check each model before adopting it.*

---

## 1. Systemic ambience (Diorama, Street)

**Principle.** Shipped games get systemic ambience from *recorded or designed samples mixed by parameters*. Neural audio generation at runtime is too slow and competes with the GPU, so it is used **offline only**.

### 1.1 Telemetry contract
The simulation host publishes `AudioTelemetry` at about 10 Hz, **aggregated per tile around the camera**. The audio layer never iterates over agents.

```
AudioTelemetry {
  tick, time_of_day, season, biome,
  wind {speed, dir}, precipitation, thunder_strikes[{pos, t}],
  water {river_flow, coastal_surf},
  crowd_density, cart_traffic_density, transit_throughput,
  alarms[{kind, pos}], ceremonies[{kind, pos}], combat_intensity,
  indoor_zone_id?
}
```

### 1.2 Mix architecture (Godot native; no middleware by default)
- **Beds (about 10 buses):**
  - wind: GDExtension noise-filter synth plus gust recordings;
  - water: 3 flow levels;
  - rain: 3 intensities plus granular drops;
  - crowd: 3 densities;
  - carts and traffic: a density bed plus clustered emitters;
  - city and transit rumble, low-passed;
  - fauna, by biome, time of day and season;
  - interior and reverb zones.
- **One-shots:** a priority pool with per-category caps, cooldowns and distance culling, using `AudioStreamRandomizer`.
  - Aggregation rules prevent spam, e.g. at most 3 sirens.
  - Thunder is delayed by distance ÷ 343 m/s and low-passed with distance.
- **Buses:** Master ← {Ambience, SFX, Music, Voice}. Voice sidechain-ducks Ambience and Music.
- **Zoom LoD:** crossfade between street, district and city beds.
- **Music:** `AudioStreamInteractive` with stems chosen by the simulation's mood: tension, mourning, festival.
- **Power:** paused means **streams stopped**, not muted. Godot's audio device can keep the PC awake; the CoreAudio fix landed in 4.8, and the WASAPI pull request is still open. Use the Dummy driver for "audio off".
- **FMOD or Wwise** only if a dedicated sound designer joins. Both are proprietary, have revenue caps, and their Godot plugins lag Godot releases.

### 1.3 Asset pipeline
- Base layers are recorded or licensed libraries.
- Variations are generated offline:
  - MOSS-SoundEffect v2 (Apache-2.0);
  - Stable Audio Open / SA3 small-sfx (free under $1M revenue, attribution required);
  - ElevenLabs SFX on a paid plan.
- Music: ACE-Step 1.5 (MIT, under 4 GB VRAM) or library music.
- **Excluded** (non-commercial licences): AudioCraft, MMAudio, TangoFlux, YuE2.
- Suno and Udio are avoided because of their litigation history.
- Every generated file carries provenance: model, prompt, seed, licence.

## 2. NPC speech (Street-Level, P6)

| Stage | Choice | Budget |
|---|---|---|
| Player voice input (optional, push-to-talk) | Moonshine streaming (MIT); alternative Parakeet-unified (CC-BY-4.0) | About 1 CPU core; 100–300 ms after end of speech |
| Turn end | Silero VAD (MIT) + Smart Turn (BSD-2) | About 10 ms |
| TTS | **Chatterbox-Nano/Turbo (MIT)** or **Pocket TTS (MIT code / CC-BY-4.0 weights)**, on 2 CPU threads via ONNX Runtime in a GDExtension; Chatterbox-Turbo on GPU if VRAM allows | About 200 ms to first audio; 0 GB VRAM on the CPU path |
| Voices | **300–600 designed voices**, made offline with Qwen3-TTS VoiceDesign (Apache), then reference clips and embeddings, plus per-NPC pitch, formant and EQ offsets. `voice_id = f(person_id, demographic bucket)` | A few MB |
| Latency masking | Pre-rendered barks per voice ("Hm?", "Aye…"); the LLM streams a sentence at a time into TTS | End-to-end 0.8–1.9 s; **AUD-4: ≤ 2 s at p95** from end of player speech to first NPC audio on the reference machine (V-AUD) |

- **Never link espeak-ng** into the binary. It is GPL-3.0 and is pulled in by sherpa-onnx TTS, Kokoro's out-of-vocabulary fallback and Piper.
- **Designed voices only.** No cloning of real people.
- Watermarking: Chatterbox's Perth watermark, or AudioSeal.

## 3. Audio drama (Narrative Compiler back end, P4+)

1. **Script.** Structured YAML/JSON scenes: speakers with voice IDs, an emotion vector, line text, nonverbal tags, SFX and music cues anchored to lines, and an ambience preset with a telemetry reference (`05.4` §5).
2. **Voice bible.** `voice_id → {model, reference clip, seed, style defaults, post chain}`. NPC-to-voice assignment is deterministic and consistent across episodes.
3. **Rendering, line by line:**
   - emotional lines: **IndexTTS-2.5** (bilibili licence: commercial use allowed under 100M MAU / RMB 1B revenue; terms must be passed downstream);
   - neutral and non-English lines: **Qwen3-TTS-1.7B** (Apache);
   - banter scenes: **MOSS-TTSD v1.0** (Apache; 1–5 speakers).
   - Fish Audio Drama 3 is a quality ceiling to evaluate. It requires < $500k revenue and attribution, which is acceptable for a personal project.
4. **QA:**
   - Whisper-turbo word-error-rate gate;
   - speaker-similarity gate against the bible clip;
   - best of 3 takes.
5. **Ambience beds.** The Diorama's audio engine, **rendered headless from the scene's real telemetry**. This makes the drama sound like the world, and it is a differentiator.
6. **Master:**
   - sidechain ducking;
   - **−16 LUFS integrated, ≤ −1 dBTP**;
   - AudioSeal watermark;
   - AI-disclosure text in the ID3 tags.
7. **Export:**
   - MP3 with ID3 CHAP/CTOC chapters;
   - `podcast:chapters` JSON and a VTT transcript;
   - a **private RSS** feed, served over the LAN, a synced folder (Syncthing + AntennaPod) or a bucket you own.
8. **Hardware.** ≥ 12 GB GPU (TTS 4–6 GB + Whisper 2–6 GB). Expect 1–3× episode length in render time with retries. Since you have unbounded compute, render on the cluster.
9. **Cloud option** (bring your own key): ElevenLabs v3 Text-to-Dialogue (up to 10 voices per request), Gemini 3.8 TTS (Voice Design, multi-speaker).

## 4. Licence verdicts (summary)

| Status | Components |
|---|---|
| **Ship-safe** | Chatterbox, Qwen3-TTS, MOSS family, ACE-Step, Moonshine, Whisper, AudioSeal, libpd, Silero VAD. Kokoro **only** without in-process espeak-ng. |
| **Conditional** | Pocket TTS (attribution), Parakeet (attribution), IndexTTS-2 (bilibili terms), Stable Audio (< $1M, attribution), Fish Drama 3 (< $500k, attribution), Higgs v2 (< 100k AAU), NeuTTS Nano/2E (< $5M) |
| **Do not ship** | F5-TTS, XTTS-v2, Fish S2-Pro, Higgs v3, Voxtral TTS, Breeze 2, OmniVoice, YuE2, AudioCraft, MMAudio, TangoFlux, VibeVoice TTS, Piper |
