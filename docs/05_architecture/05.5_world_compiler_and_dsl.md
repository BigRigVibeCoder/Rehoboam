# 05.5 — World Compiler, Mechanics Registry and the World DSL

*Status: Draft v1.0 (2026-10-15). Sources: R05, R09, R02. Decisions: ADR-0010. Machine-readable artefacts: `specs/manifest/manifest_v0.py` (Pydantic v2), `specs/manifest/examples/*.yaml`.*

---

## 1. Principles

1. **The Registry is the language.** A manifest can only reference what the engine implements: systems, archetypes, act classes, roles, goods, technologies, laws, channels and pattern packs. Free strings never carry semantics.
2. **Small intent, deterministic bulk.** The LLM writes a short *intent*. A deterministic expander generates the full world. No LLM ever writes 100,000 citizens.
3. **Valid means simulable *and* plausible.** Schema validity is necessary but not sufficient. Every compiled world must pass semantic validators and a burn-in run against the stylized facts.
4. **What the Registry can't express is reported, not faked.** Unexpressible requests become **gap reports**, which feed the engine's evolution (success criterion S4).
5. **Hand-authoring comes first.** Manifests are human-readable YAML that you can write and diff directly. The LLM is an optional front end.

## 2. Mechanics Registry

The Registry is versioned (semver) and lives in `registry/*.toml`. The JSON Schema for manifests is **generated from it**, as are the enums used in constrained decoding.

| Registry section | Entries (examples) | What an entry declares |
|---|---|---|
| `systems` | `M1.regions@F1`, `M2.demography@F1`, `M5.contagion@F1`, … | Fidelity levels, parameter schema with **bounds**, clocks, emitted event types |
| `archetypes` | `human`, `apex_predator`, `hive_node`, `beast_of_burden`, `automaton` | Ledger table, components, life history (lifespan, fertility), energetics, capabilities (`flying`, `bondable`, `covert_capable`) |
| `act_classes` | `harm`, `aid`, `betray`, `infect_convert`, `succeed_to`, … | Default tellability, affect signature, roles |
| `roles` | `authority`, `successor`, `kin(n)`, `investigator`, `suspect`, … | Binding rules from concrete titles and relations |
| `verbs` | `ISSUE_DECREE`, `ARREST`, `RAID_LIVESTOCK`, `BLOOD_TEST`, … | Act-class mapping, preconditions, effects, which past-event roles can be referenced (**contingent unlocking**) |
| `goods` | grain, livestock, timber, ore, cloth, tools/arms, luxuries; modern: energy, medicine, test kits, services | Production function, perishability, base price |
| `technologies` | heavy plough, crop rotation, printing, gunpowder, germ theory, PCR testing… | DAG edges, effects on A, k₀, W, IFR, se/sp |
| `institutions` / `laws` | succession: `primogeniture`, `partition`, `seniority`, `elective`, `tanistry`, `sortition`; taxation; testing mandates | Mechanics hooks and parameter bounds |
| `channels` | `witness`, `testimony`, `document`, `crowd`, `whisper`, `hive` | Latency, fidelity, trust, and reach parameters |
| `overlays` | `paranoia`, `filial_piety`, `despair`, `hubris`, `corruption`, `dragon_sympathy` | Derivation formula over the psychological core |
| `pattern_packs` | `succession`, `covert_infiltration`, `famine`, `revenge`, `plague_era` | Sifting patterns (`05.4`) |
| `style_cards` | `mythic_chronicle`, `deep_time`, `saga`, `historian`, `noir_city` | Narrative style |
| `scenario_templates` | `feudal_realm`, `merchant_republic`, `modern_metropolis` | Default system sets, fidelity profiles, horizons |

## 3. The manifest (v0 structure)

The full schema is in `specs/manifest/manifest_v0.py`. Top level:

```yaml
manifest_version: 0
registry_version: "0.1.0"
world:
  id: val_khor
  display_name: "The Caldera of Val-Khor"
  template: feudal_realm
  seed: 1207
  calendar: {days_per_year: 360, months: 12, seasons: 4, epoch_label: "Year of the Sun-Spire"}
  horizon: {years: 1000, label: historical}        # historical | speculative
  fidelity_profile: {M2.demography: F1, M4.economy: F1, M5.contagion: F1, ...}
geography:
  raster: {resolution: 1024}
  regions: {count: 600}
  heightmap_template: caldera_with_passes
  climate: {zone: temperate_continental, harvest_sigma: 0.2, autocorr: 0.35, volcanic_rate: 0.004}
peoples:
  - archetype: human
    population: 100000
    cultures: [...]
    faiths: [...]
  - archetype: apex_predator
    variant: dragon
    population: 45
    params: {mass_kg: 5000, metabolism_multiplier: 0.3, flying: true, bondable: true}
polities:
  - id: house_khorvath
    government: feudal_monarchy
    succession_law: primogeniture
    titles: {authority: High_King, successor: Crown_Prince, ...}
systems:
  M2.demography: {e0: 32, tfr: 5.2, elite_fertility_mult: 1.2}
  M6.polity: {tax_rate: 0.15, psi_threshold: 1.8}
  ...
catalysts:                    # initial conditions + probabilities, never forced outcomes
  - kind: dynastic_tension
    subjects: {authority: "house_khorvath.ruler", successor: "house_khorvath.heir"}
    initial: {opinion_successor_of_authority: -30, fear_authority: 0.5, heir_age_years: 24}
  - kind: artifact
    name: "The Ember Crown"
    effects: [{overlay: dragon_sympathy, holder_delta: +0.4}]
overlays: [paranoia, filial_piety, dragon_sympathy]
narrative:
  pattern_packs: [succession, revenge, famine, dragon_age]
  default_style_card: mythic_chronicle
presentation:
  era_art: early_medieval
  palette: ember_and_slate
```

Notes:
- `macro_dimensions` from the draft is replaced by **raster resolution** plus **region count**. Both are fidelity knobs.
- The draft's `CatalystRule{trigger_event, consequence_action}` is replaced by **catalysts as initial conditions** plus **pattern packs**: drama is detected rather than scripted. If a world needs a mechanic the Registry lacks, that gap is reported (§6).

## 4. Compile pipeline

```mermaid
flowchart TB
  P[Natural-language prompt] --> I[Intent LLM<br/>reason freely, then emit Intent JSON<br/>enums generated from Registry]
  I --> X[Deterministic Expander<br/>template defaults · cultures/names · polities · genealogies · catalysts → manifest]
  X --> V1[Schema validation<br/>Pydantic + generated JSON Schema]
  V1 --> V2[Referential validation<br/>all IDs resolve · roles bind · laws exist]
  V2 --> V3[Semantic validation<br/>population ≤ k·K · energetics (predator mass vs prey biomass) · TFR/e0 guard · horizon vs template]
  V3 --> B[Burn-in: 200 years × 8 seeds, headless<br/>stylized-fact bands · bad-run rate]
  B -->|pass| H[Hash manifest → input journal<br/>world ready]
  V1 -->|errors| R[Repair loop ≤3<br/>machine-readable errors back to Intent LLM]
  V2 -->|errors| R
  V3 -->|errors| R
  B -->|fail| R
  R --> I
  I -.unexpressible concepts.-> G[Gap report → backlog]
```

**The Intent object** is deliberately small, roughly 20–60 fields, and has three parts:

1. **Template:** one Registry choice.
2. **Overrides:** bounded numbers and enums.
3. **Flavour seeds:** names and short prose used as seeds for culture and naming generators, never as mechanics.

The expander does the rest. All fields are enums or bounded numbers, so constrained decoding is reliable (R05 §5). The model reasons first, in a free text field or a thinking block, and is then constrained. That ordering is the CRANE finding.

**Model choice.** The best available frontier model, for example Claude Sonnet/Opus 5.5 with native structured outputs: a compile costs well under $0.10. The local fallback is the resident model through llguidance. Free tiers are never a dependency.

**Burn-in cost.** 200 years × 8 seeds at 100k persons runs in about 30–60 s on a desktop and is parallel across seeds (`08`).

## 5. Validators (initial set)

| Validator | Rule |
|---|---|
| Carrying capacity | Initial population ≤ 1.2 × Σ K_region given land, yield and technology |
| Vital-rate guard | Pre-modern burn-in mean r ∈ [−0.1, +0.3] %/yr unless a technology trajectory is declared |
| Energetics | Predator standing biomass ≤ 0.009 × prey and livestock biomass × metabolism multiplier (Carbone ratio) |
| Horizon | `modern_*` templates with horizon > 50 years require `horizon.label = speculative` and a declared technology and institution trajectory |
| Succession | Every polity has an authority, a law, and an eligible successor pool > 0 |
| Covert contagion | If a covert compartment is present, the testing technology and channel exist, and se/sp lie within bounds |
| Narrative liveness | Burn-in yields ≥ N completed pattern matches per century (MOE-6 guard) |
| Overlays | Every overlay's derivation resolves against the psychological core |

## 6. Gap reports

```json
{
  "gap_id": "gap-2026-10-15-0007",
  "prompt_fragment": "succession by lottery among all citizens",
  "closest_supported": "succession.sortition (council members only)",
  "approximation_used": "sortition among council (flagged in manifest)",
  "proposed_registry_change": {
    "kind": "law",
    "id": "succession.sortition_citizenry",
    "mechanics": "uniform draw over adult citizens of the polity's core regions at ruler death; legitimacy modifier −0.2 among elites",
    "affected_systems": ["M7.dynasty", "M6.polity"],
    "tests": ["eligibility pool", "legitimacy shock", "elite revolt hazard"],
    "estimate_agent_days": 1
  }
}
```

Gap reports are filed into `backlog/gaps/` and become agent work packages (`13_agentic_development_playbook.md`). Over time the Registry grows in whatever direction your imagination pushes it.

## 7. Worked mappings (draft prompts → Registry)

**"100,000 people in a feudal system with dragons, driven by a father-son succession catalyst"**
- Template: `feudal_realm`.
- `peoples`: human 100k plus `apex_predator{dragon}`, bounded by energetics (Carbone ratio). The draft's 45 five-tonne dragons need about 25,000 t of standing prey at metabolism ×1, but a 100k-person realm's livestock is about 15,000 t, which supports about 135 t of predator. The validator flags this unless wild prey is declared or the metabolism multiplier is lowered. This exact case is checked in `specs/manifest/examples/invalid_draft_style.yaml`. The reference world `val_khor.yaml` uses 12 dragons at metabolism ×0.5.
- Polity: primogeniture.
- Catalyst: `dynastic_tension(ruler, heir)` with initial opinion and fear values.
- Artefact catalyst: a dragon-bonding relic (`overlay: dragon_sympathy`).
- Pattern packs: `succession`, `dragon_age`, `revenge`.
- Gap report (likely): "dragon-bonding" mechanics beyond an overlay. Proposed as `capability.bondable` plus an `act_class.bond` verb.

**"A modern 1-million-person city with an infiltrating hive-mind virus discoverable only via blood tests"**
- Template: `modern_metropolis`. Horizon 10 years, label historical; day/week clocks.
- Contagion: M5 with a covert compartment (latent ∞, chronic), `channel.hive`, a `technology.blood_assay` with se 0.95–0.99 and sp 0.98–0.999, a testing-mandate institution, and fear coupling.
- Archetypes: human 1M plus a `hive_node` capability on infected persons.
- Pattern packs: `covert_infiltration`, `plague_era`, `witch_hunt`.
- The base-rate dynamics produce the detection spiral without scripting it.
